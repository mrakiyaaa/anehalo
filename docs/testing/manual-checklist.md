# Windows release checklist

Run on a clean Windows 10/11 VM with a standard, non-administrator account. Record Windows/WebView2 versions, installer SHA-256, tester, date, and pass/fail evidence. Use a disposable vault with known Markdown and image files. Do not use personal notes. Unchecked items are **unverified**, not passed by the automated suite.

- [ ] **Install:** Run `Anehalo_0.1.0_x64-setup.exe` without elevation. Expect a per-user installation, the Anehalo icon and correct version/publisher in Installed Apps, and a working Start-menu shortcut. WebView2 may need installation if absent. Document any prerequisite elevation separately.
- [ ] **First run:** Launch from Start, finish onboarding with a name and custom notes directory. Expect the home screen, a welcome note for an empty vault, and settings under `%APPDATA%\me.lakshitha.anehalo`. Repeat in another Windows user with Skip setup; expect Documents\Anehalo.
- [ ] **Vault location isolation:** In onboarding choose Documents, Desktop, and a personal subfolder on another drive in separate disposable profiles. Expect the final path ending in `Anehalo` before continuing and the sentence “Anehalo creates its own folder here and never touches your other files.” Put many files in a sibling folder first; expect a responsive workspace within two seconds and no sibling files in the note list or changes to them. Verify the welcome note is inside the new child folder. Repeat through Settings and check the final path in its confirmation dialog.
- [ ] **Restore a copied vault:** Copy disposable notes into an existing folder named `Anehalo` (repeat with `aNeHaLo`). Select that folder in onboarding and Settings. Expect the existing notes, no nested `Anehalo` folder, unchanged note bytes, and the same vault after restart. A file named `Anehalo` in a selected parent must produce a clear error, without overwriting it.
- [ ] **Location validation:** Try a drive root, Windows, Program Files, ProgramData, AppData, a junction/symlink, a missing location, a read-only location, and a path exceeding 240 characters after adding the child folder. Expect a clear rejection for each, a usable chooser afterwards, and no parent-folder access grant. Use a disposable network share to test a UNC subfolder, Unicode, emoji, and spaces.
- [ ] **Startup recovery and scan limits:** With the app closed, set a disposable profile's saved vault to a missing path, an unreadable folder, and an old custom parent not named `Anehalo` containing over 200 entries. Expect “Choose a folder again” and “Use the default folder” with no retry loop. Test a real `Anehalo` folder containing 20,001 entries; expect “This folder has too many items to be a notes folder”. Test recovery through both buttons, then restart. Expect only the selected/default vault loaded and all original files retained. Confirm dot-folders, junctions, and non-Markdown files are absent from the note list; managed images and trash must still work.
- [ ] **Global shortcut:** With another application focused, press `Ctrl+Alt+N`. Expect Anehalo to show and a new focused note. Change the shortcut in Settings and repeat. Assign one already used by another app; expect a clear error and the previous shortcut to continue working. Test while a note has unsaved text.
- [ ] **Open/toggle shortcut:** With an existing note open, test `Ctrl+Alt+A` while hidden in the tray, minimized, and visible behind another app. Expect show, restore, focus, the same note and selection, and no new file. With Anehalo focused, press again: expect hide when Keep running in the tray is on, minimize when off. Type immediately before hiding and inspect the Markdown on disk; expect the latest text saved. Simulate a save failure and expect the window to remain visible with its draft and a clear error. Repeat from Home, search, and Settings; expect the last view retained.
- [ ] **Two shortcut settings:** Record a new Open Anehalo shortcut, test it from another application, restart, and expect it persisted. Reset both fields and test the defaults. Attempt the same combination in both fields, including reversed modifier order; expect a clear different-shortcuts message, unchanged settings, and both previous bindings still working. Try an externally occupied combination and expect the same conflict recovery as quick notes. While recording either field, expect neither global action to fire. Upgrade a profile whose quick-note binding is Ctrl+Alt+A; expect it preserved and Open Anehalo on Ctrl+Alt+O.
- [ ] **Command-line actions and Windows shortcut keys:** Quit Anehalo and launch the installed executable with `--new-note`. Expect exactly one new focused note after loading (finish onboarding first on a new profile). Repeat while already running, hidden, minimized, and immediately during startup. Expect forwarding to the existing instance, one new note per launch, and one tray icon. Repeat `--open` and a launch without arguments; expect the existing view and no new note. An unknown argument must show a clear launch error. Create separate Windows shortcuts targeting `anehalo.exe --open` and `anehalo.exe --new-note`, assign unused keys in Properties → Shortcut key, and test with the app closed and running. Verify both Start menu and desktop shortcuts exist after a normal installer run.
- [ ] **Tray:** Enable Keep running in the tray. Type, close the window, and inspect the Markdown on disk. Expect the latest text saved and the process to remain in the tray. Left-click its icon to restore; click again to hide, preserving the current note and pending saves. Right-click and try Open Anehalo, New quick note, Settings, and Quit. Open must preserve the current view; New quick note must create a note. Quit must save notes/settings, release both shortcuts, and remove the tray icon. Repeat with Keep running disabled; closing must exit.
- [ ] **Autostart:** Enable Start with Windows. Sign out and back in. Expect Anehalo in the tray with no initial window; shortcut and tray restore should work. Disable it, sign out/in again, and expect no Anehalo process. Test with an ordinary user account.
- [ ] **Single instance:** Launch Anehalo twice from Start and then run the executable from Explorer. Expect one process/window and restoration of an existing minimized/hidden window, with no extra tray icons or loss of text.
- [ ] **Keyboard and screen reader:** Tab through home, editor, search, menus, onboarding, and Settings in both themes. Expect visible focus, meaningful labels, Escape to close dialogs, restored focus, and no keyboard trap. Check Narrator, 125%/150% display scaling, and high contrast.
- [ ] **Native dialogs:** Export Markdown with images and PDF to a new folder. Cancel each dialog once. Expect no partial output on cancellation and correct image references/assets after success. Open the PDF and check Sinhala/Tamil glyphs, page breaks, and tables.
- [ ] **Read-only vault:** Revoke the test account's write access to its disposable vault while the app is running. Edit a note and close. Expect a visible save error, the window to stay open, and the original file intact. Restore access, Retry, then close and verify the latest text. Repeat during onboarding; it must reject the folder.
- [ ] **Deleted vault:** While editing, rename the disposable vault in Explorer. Edit/close. Expect a recoverable missing-file error, retained editor text, and no silent replacement of the vault. Restore its original path and use the recovery action; verify text on disk.
- [ ] **Disk full:** Place a disposable vault on a small test VHD, fill that VHD, edit a note, and close. Expect a failed-save notice, retained text, and the original Markdown intact. Free space and retry. Never fill the system drive. Unit tests cover injected disk-full failures; this checks the operating system behavior.
- [ ] **Long/unusual names and large notes:** Create a title of 1,000 characters, names containing Sinhala, emoji, quotes, `?`, `:`, and Windows reserved names (`CON`, `NUL`). Expect safe bounded filenames, preserved Unicode, reserved-name errors, and no traversal. Open/edit/save/restart a 1 MB note; expect exact saved content and a responsive app.
- [ ] **Logging:** Trigger a failed save and inspect `%LOCALAPPDATA%\me.lakshitha.anehalo\logs`. Expect an event and error code, no title, path, note body, stack, or raw error message. Logs rotate at 1 MB and retain three archives. Debug isolated runs use their temporary runtime folder.
- [ ] **Uninstall preservation:** Before uninstall, hash notes, images, `.trash`, and settings. Quit Anehalo, uninstall via Installed Apps as the same non-admin user, and verify hashes and paths remain. Test both silent uninstall and interactive uninstall with any “delete app data” box selected: the hook must override deletion. Repeat with a custom vault. Expect binaries/shortcuts removed and user data retained. Reinstall and expect the same settings and notes.
- [ ] **Clean restart:** Restart Windows and reopen after installation/reinstallation. Expect no console errors and working shortcuts, tray, export, image loading, and remembered theme/vault.
